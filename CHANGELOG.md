# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.1.0] - 2025-05-15

### Added
- Complete implementation of the `FocusTimer` state machine with customizable intervals.
- Advanced celestial canvas animations in `OrbitApp` featuring smooth planet orbiting around a radiant sun.
- Fully integrated procedural audio synthesizer (`SoundSynthesizer`) using NumPy for beeps, chimes, and ambient background frequencies.
- Session tracking statistics dashboard within the UI.
- Comprehensive unit support and full module integration across `src/`.
- Documentation updates including README and initial CHANGELOG.
